관리 키에서는 API 키 발급, quota 확인, 사용량 점검, 고급 동시 요청 설정까지 한 흐름으로 관리할 수 있습니다. 일반 API 키로 접속하면 본인 quota와 사용량만 간단히 확인합니다.

엔드포인트: /v0/quota-status 계정 토글: /v0/management/auth-files/status

설정 방법 요약

현재 quota 페이지와 같은 호스트를 기준으로 잡고, 필요한 경로만 붙여 바로 연결하면 됩니다.

OpenAI API compatible

OpenAI 호환 SDK·CLI는 보통 OPENAI_BASE_URL 과 OPENAI_API_KEY 만 맞추면 됩니다.

  • Base URL은 /v1 까지 포함합니다.
  • API 키는 quota 페이지를 열 때 쓰는 일반 API 키를 넣으면 됩니다.
  • POST /v1/images/generations 는 prompt만으로 새 이미지를 생성할 때 사용합니다.
  • POST /v1/images/edits 는 첨부 이미지를 수정하거나 참고 이미지로 쓰는 흐름에 사용합니다.
  • 이미지 첨부는 multipart/form-data 로 image 또는 image[] 파일 필드를 보내면 됩니다.

Claude Code

Claude Code는 ANTHROPIC_BASE_URL 과 ANTHROPIC_AUTH_TOKEN 을 쓰고, 기본 모델은 환경 변수로 고정할 수 있습니다.

  • Base URL은 현재 origin 뒤에 /api/anthropic 를 붙인 값으로 맞춥니다.
  • 기본 모델은 ANTHROPIC_DEFAULT_* 환경 변수로 고정할 수 있고, 값은 서버가 노출한 alias와 정확히 같아야 합니다.

관리 키는 운영 화면용이고, 실제 툴 연결에는 클라이언트 API 키를 사용하는 편이 안전합니다.

브라우저는 키를 저장하지 않습니다. 관리 키는 전체 API 키 운영 화면을, 일반 API 키는 본인 quota와 사용량 화면만 보여줍니다.

경로별 예외 제한

특정 API 키 개별 제한 요약

새 override를 빠르게 추가할 때만 여기서 입력하세요. 이미 있는 override의 확인·수정·삭제는 위 API 키 quota 카드에서 바로 처리할 수 있습니다.

연동 계정 처리 현황

연동 계정별 요청 수 제한은 여기서 보기만 할 수 있습니다. 현재 적용된 한도와 처리 중인 요청 수를 함께 확인하세요.

연동 계정 운영 상태

연동 계정은 quota 분모가 없어서 퍼센트 대신 상태와 최근 24시간·7일 활동량 중심으로 보여줍니다. API 키 운영과 함께 계정 처리 상태를 점검하는 구간입니다.

OpenRouter 키 추가

OpenRouter 계정을 새로 등록하는 곳입니다. 키를 저장하고 필요하면 지출 한도도 함께 적어둘 수 있습니다.

OpenRouter 모델 연결 설정

기존 openai-compatibility 의 name=openrouter 항목을 수정합니다. 여기서 OpenRouter에 보여줄 모델 목록과, 필요할 때만 모델별 연결 우선순위를 함께 저장합니다.

아래 목록은 JSON 형식으로 저장합니다. provider 칸은 꼭 넣지 않아도 되고, 특정 회선을 우선 쓰고 싶을 때만 채우면 됩니다. 예: [{"name":"openai/gpt-5-mini","alias":"gpt-5-mini","provider":{"order":["openai"],"allow_fallbacks":false}}]
